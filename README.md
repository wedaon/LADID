## Unity prototype

Unity 2022.3 project for a 2D top-down survival game. Open this repository in Unity Hub, let the scripts compile, then use **LADID > Create Prototype Scene** and press Play.

- **WASD / arrow keys:** Move the square player around the rectangular field.
- **Volcanic dimension:** Red circles warn where meteor debris will fall. Leave the marked area before impact.
- **Tidal dimension:** A horizontal wave sweeps across a marked lane. Move up or down to dodge.
- Every 22 seconds, the dimension collapses and switches to the other environment. Survive with three lives; press **R** to restart after losing.
